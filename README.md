# 🏎️ RC Battleground – Precision RC Vehicles & Motorsport E-Commerce Platform

RC Battleground is a modern, high-performance web application and e-commerce platform built for remote control (RC) vehicle enthusiasts, drift masters, monster bashers, scale crawlers, and FPV racers.

---

## 🌟 Key Features

- **🏎️ Dynamic Product Catalog**: Filter RC vehicles by categories (Off-Road Buggies, Drift Cars, Monster Trucks, Rock Crawlers, Speed On-Road, Racing Drones) with dual-currency support (NPR & USD).
- **🛒 Real-Time Stock Management**: Automated stock deduction upon buyer checkout and stock restoration upon order cancellation.
- **🛠️ Admin Control Panel**: Complete vehicle inventory management, specifications editing, dynamic category CRUD (Create, Edit, Delete), order fulfillment, user permissions, and sales analytics.
- **👑 Memberships & Reward Points**: Tiered memberships (Standard, Pro Pass, Elite Pass), reward points calculation, redemption value conversion, and transaction history.
- **🌗 High-Contrast Light & Dark Theme**: Ultra-readable motorsport design system with Orbitron typography and seamless theme switching.
- **🔐 User Verification & Security**: Dual OTP and device link email/SMS account verification with permanent PostgreSQL data persistence.

---

## 🚀 Stack & Technologies

- **Frontend**: React, Vite, TailwindCSS, Lucide Icons, Context API
- **Backend**: Node.js, Express.js, PostgreSQL (`pg`), JSON Web Tokens (JWT), BcryptJS
- **Services**: SMTP Email Dispatch, SMS Gateway Integration, Currency Exchange API

---

## 🛠️ Quick Start

```bash
# 1. Install dependencies
npm run install-all

# 2. Run backend and frontend concurrently
npm run dev
```
